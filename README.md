# Address Book Management System in C

## Project Overview
The Address Book Management System is a console-based application developed using C programming. It allows users to manage contact information efficiently through a simple menu-driven interface.

## Features
- Add new contacts
- Search for contacts
- Edit existing contact details
- Delete contacts
- Sort contacts
- Validate names, phone numbers, and email addresses

## Technologies Used
- C Programming
- Structures and Functions
- File Handling (if implemented)
- Input Validation
- Data Management

## How to Run
1. Download or clone this repository.
2. Extract `SakshiAddressBookProject.zip`.
3. Open the source code in a C compiler or IDE.
4. Compile the C source file(s).
5. Run the executable and follow the menu options.

### Compile using GCC
If the project contains a C source file named `main.c`, compile it using:

```bash
gcc main.c -o addressbook
```

Run on Linux:

```bash
./addressbook
```
